Connection

Direct mode is right for local testing. Before selling philform, switch to a hosted backend: an unpacked extension's source is readable by anyone who installs it, so a shipped API key is a published API key.

Field matching

On the twenty-field benchmark in tools/test-live.py both placed every field correctly. TypeSafe was about five times cheaper and eight times faster, and it answers with a typed choice, so it can only return a value your profile actually holds or an option the page actually offers.

Below this, a field is filled with a best guess outlined in amber for you to check. 0.6 is a sensible default.

Matching a stored value to a labelled box needs no deliberation, and reasoning tokens are billed at the output rate. None is the right default here.

Writer

Thinking is billed at the output rate and is poor value on these prompts: Low cost roughly eight times more than None for answers of the same quality.

How matching works phil finds the right saved answer however a form words the question.

phil reads each long question on the page and decides whether one of your saved answers answers it, by meaning rather than wording. "Where do you see yourself in five years", "What are your long-term career goals" and "Describe your career aspirations" all find the same saved answer. You do not have to anticipate the phrasing.

The answer text itself is the main signal, so write it as you would actually submit it. Example phrasings are optional: they are a shortcut that skips the matching step when the wording is exact, not a requirement.

Use {{company}} and {{role}} to drop in the employer and job title from the page you are applying on. Any profile field works too, such as {{identity.firstName}}. A placeholder with nothing to fill it is removed.

One skill per site. phil records every field a site offers, whether or not it managed to fill it, so the ones it got wrong are visible and correctable. A remembered field is answered with no model call, which is what makes a second application on the same site fast.

Fields needing attention are listed first. Set what a field should draw on, then save. Changing a row locks it, so a later run never overwrites your correction.

Portable configuration Back up your setup, or move it to another browser.

Export writes a single file holding everything ticked below. Import it on another browser or another machine to arrive with the same setup. The same file works for both Chrome and Firefox.

Off by default. An export usually ends up in a downloads folder or a chat message, and anyone holding the file could then spend against your account. Tick it only when you are moving machines, and delete the file afterwards.
